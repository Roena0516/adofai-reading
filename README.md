# ADOFAI 타법 리더

불과 얼음의 춤(A Dance of Fire and Ice) 커스텀 레벨을 건반 리듬게임처럼 손가락 레인으로 펼쳐 보여주고,
자기 타법대로 키보드로 연습할 수 있는 웹 앱입니다.

배포: https://adofai-reading.vercel.app

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:5199
```

레벨 zip(또는 `.adofai`와 음악 파일)을 화면에 끌어다 놓으면 됩니다. 파일은 브라우저 안에서만 읽습니다.
Chrome 기준으로 만들었습니다. Safari는 ogg 음악을 재생하지 못해 무음으로 열립니다.

## 명령

| 명령                              | 내용                                                                    |
| --------------------------------- | ----------------------------------------------------------------------- |
| `pnpm dev`                        | 개발 서버                                                               |
| `pnpm build`                      | 정적 사이트 빌드 (`apps/web/dist`)                                      |
| `pnpm test`                       | 코어 테스트 (프로젝트 루트에 테스트 zip이 있으면 실제 레벨 검증도 실행) |
| `pnpm lint` / `pnpm typecheck`    | ESLint / TypeScript 검사                                                |
| `pnpm dump "<레벨.zip>" [--base 2 | 4] [--notes 40]`                                                        | 엔진이 읽은 타이밍·기준 BPM·연타·손가락 배정을 터미널에 출력 |

## 구조

```
packages/core   순수 TypeScript 엔진 (브라우저·Node 공용)
  parse/        관대한 JSON 파서, pathData → angleData, 레벨 설정
  timing/       타일 각도·BPM·Twirl·미드스핀·Pause → 노트 시각
  rhythm/       기준 BPM 구간 감지, 따닥 묶기, 연타(런)·비트 분할·강박
  fingering/    레인(손가락) 모델, 순서 문자열, 타법 프로필(2키/4키 기반), 배정기
  practice/     레인 단위 판정, 통계
apps/web        React 19 + Vite + Zustand + Tailwind, Canvas 렌더러, Web Audio 엔진
```

## 사용법 요약

- **타법 탭**: 레인은 항상 8개(1 L소 … 4 L검 | 5 R검 … 8 R소)입니다. 기준 BPM(×2·÷2), 주손, 굴리는 방향(안밖·밖안·계단), 기반(2키·4키), 키 바인딩, 동타 설정만 고릅니다.
  - 2키 기반: 8비트 이하 1키, 12·16비트 양손 트릴, 24비트 3키, 32비트 이상 4키
  - 4키 기반: 4비트 이하 1키, 8비트 양손 트릴, 12비트 3키, 16비트 4키, 24비트 6키, 32비트 이상 8키
  - 헤더에서도 기반을 바꿀 수 있고, 레벨의 한 구간만 다르게 치려면 일시정지한 뒤 레인 옆 카드에서 "#번호부터 2키/4키"를 고릅니다.
- **구간 탭**: 기준 BPM 구간을 고치거나, 타일 범위에 순서(`3412`)나 노트별 표기(`3222322232232232`)를 직접 지정합니다. 키 기반 전환 목록도 여기서 보고 지웁니다.
  일시정지 상태에서 노트를 끌어 다른 레인으로 옮기거나 클릭해서 손가락을 바꿀 수 있습니다.
  바꾼 노트는 바로 브라우저에 저장되고, 일시정지하면 레인 옆 카드에서 개수를 보고 JSON으로 내보내기·가져오기·모두 되돌리기를 할 수 있습니다.
- **연습 모드**(`Tab`): 지정한 키로 치면 타이밍과 손가락을 함께 판정하고, 통계 탭에서 손가락별 오차와 약한 연타 구간을 보여줍니다. 판정 범위는 얼불춤과 같습니다. 행성 각도로 ±30° 완벽, ±45°까지 빠름·느림(노란색), ±60°까지 빠름·느림(빨간색)이고, 그보다 일찍 누르면 너무 빠름입니다. 빠른 곡에서는 설정 탭의 판정 기준(느슨·보통·엄격)에 따른 최소 범위보다 좁아지지 않습니다. 얼불춤 화면에서는 행성이 내가 누른 순간에 다음 타일로 넘어가고, 판정 글자가 타일 위에 뜹니다.
- **얼불춤 화면**: 레인 오른쪽에 실제 게임처럼 타일과 행성을 보여줍니다. 레벨의 카메라 이동, 타일 이동·등장 효과, 트랙 색을 그대로 적용하고, 타일마다 칠 레인 번호를 배지로 표시합니다.
  - 화면 효과: 배경 이미지와 색, 플래시, 화면 흔들림, 행성 회전 이징.
  - 필터와 블룸(WebGL): 흑백, 세피아, 반전, 대비, 색수차, 어안, 물결, 글리치, VHS, 80년대 TV, 아케이드, LED, 압축, 네온, 드로잉, 노이즈, 모션 블러, 눈, 눈보라, 비, 꽃잎 등. 게임 셰이더의 근사치입니다.
  - 장식(이미지와 글자)은 타일을 가릴 수 있어서 기본으로 꺼져 있습니다. 설정 탭에서 켤 수 있습니다.
- **레벨 고르기**: zip 안에 레벨 파일이 여러 개 있으면(난이도별 레벨 등) 열기 전에 고를 수 있습니다. 노트 수, BPM, 길이가 함께 나옵니다.
  - 판정에 따라 실행되는 효과(SetConditionalEvents)와 SetFilterAdvanced, 배경 영상은 지원하지 않습니다.
- **동타 표시**: 설정 탭에서 따닥을 실제 시각대로 그릴지, 첫 노트 시각에 나란히 그릴지 고를 수 있습니다.
- **한손 동타**: 30°·15°처럼 날카롭게 꺾이는 따닥은 한 손의 이웃 손가락으로 배정합니다. 각도와 방향은 타법 탭에서 바꿉니다.
- **노트 옮기기**: 일시정지한 상태에서 노트를 다른 레인으로 끌어다 놓으면 그 노트만 손가락이 바뀝니다.

## 알려진 제한

- Hold(롱노트) 길이 규칙은 공개 자료가 없어 "1 = 한 바퀴"로 추정합니다. 해당 레벨을 열면 경고가 뜹니다.
- 3행성(MultiPlanet), FreeRoam 구간의 타이밍은 아직 지원하지 않습니다.
- 다각형 타일 문자(`5 6 7 8` 등)의 각도는 ADOFAI-JS 값을 따른 추정치입니다.
